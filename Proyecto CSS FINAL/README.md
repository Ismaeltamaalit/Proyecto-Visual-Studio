# VG.BLOG — desarrollo local

Comandos rápidos:

- Iniciar servidor local (usa npx, funciona sin instalación global):

  npm start

- Abrir en navegador: http://localhost:8000/

Notas:
- Páginas principales están en carpetas (`index/`, `reviews/`, `noticias/`, `guias/`, `contacto/`).
- Si prefieres instalar `http-server` globalmente: `npm i -g http-server` y luego `http-server -p 8000`.
